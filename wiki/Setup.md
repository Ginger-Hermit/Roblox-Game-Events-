# Step-by-step guide

![2 minutes](https://img.shields.io/badge/time-2%20minutes-2ea44f) ![Phone](https://img.shields.io/badge/works%20on-phone-1F3864)

</div>

> [!NOTE]
> You need to be an admin (or have "Manage Webhooks") in the Discord server you want posts in.

## Step 1: Copy the game link
1. Open the game in the Roblox app or website.
2. Tap **Share**, then **Copy link**.

## Step 2: Make a Discord channel link (webhook)
1. In Discord, open your server.
2. Long-press (or right-click) the channel you want posts in.
3. Tap **Edit Channel**.
4. Tap **Integrations**, then **Webhooks**.
5. Tap **New Webhook**, then **Copy Webhook URL**.

> [!WARNING]
> Keep this link private. Anyone with it can post in that channel.

## Step 3: Start it
1. Open [the website](https://roblox-game-events.pages.dev).
2. Paste the game link in box 1.
3. Paste the channel link in box 2.
4. Tap **Send a test**. A post should show in your channel.
5. Tap **Start**.

> [!TIP]
> Done. New events now post once a day. Tap **Stop** any time to delete your details.
