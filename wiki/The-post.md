Each event shows up in Discord as one card.

| Line | Meaning |
|---|---|
| **New [game] event** | Which game it's from |
| **Title** | The event's name. Tap to open the event page. |
| **Description** | The event's text from Roblox |
| **Starts / Ends** | Shown in your own time zone |
| **Starts in** | Live countdown |
| **Type** | The kind of event, from Roblox |
| **Interested** | Players who tapped "Notify me" |
| **Play now** | Opens the game |
| **Picture** | The event's thumbnail, if it has one |
| **Small picture** | The game's icon |

Fields show "not recorded" style gaps when Roblox doesn't give them.
